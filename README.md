# Serenity · Prototipo funcional

Prototipo web móvil (datos de ejemplo) para el testeo de usabilidad. Proyecto de Título INACAP.

Flujos: onboarding, Inicio, crear/revocar pase, pagar gastos comunes, reservar quincho, enviar y ver solicitud, retirar encomienda.

```
npm install
npm run dev      # desarrollo
npm run build    # producción (carpeta dist)
```

Despliegue: importar el repo en Vercel (preset Vite, sin configuración extra).
En Perfil → "Restablecer demo" vuelve todo al estado inicial entre participantes.
